P0-1 组合反馈（核心需求，先做）
------------------------------------------------------------
目标：文字、拍照、语音三通道【平级可选、任意组合】，
     可只用一个、任意两个或三个一起；三通道全空才拒绝提交。

前端改动
  - app/templates/portal/report.html
     1) 文字区 <textarea id="text" maxlength="2000"> → maxlength="1500"，
        加小字提示"可不填，若选语音/照片则自动补充"；
        现有 TextDetector OCR（截图识字）保留。
     2) 照片区保留 id="screenshots" multiple + capture；
        label 改为"最多 10 张"；前端校验 files.length > 10、单张 ≤5MB。
     3) 【新增语音区】一个大录音按钮（按住说话/点击切换）+ 状态提示 +
        试听 <audio> + 重录/删除按钮；语音作为第三个平级通道入口，
        不是"降级替补"，与文字/照片平级。
     4)【新增汇总条】顶部实时"已选：☑文字 ☑照片(2) ☑语音"，三通道状态可视化。
     5) 提交校验把现有 text.length<5 硬校验放宽：
        · 有照片或语音 → 允许 text 短至 0（normalize 后仍可空）；
        · 三通道全空 → 前端提示"至少选一种反馈方式"，不发库。

语音四状态机（只管语音通道内部，作用域收窄）
  状态        表现
  未问过      大字按钮，点击才请求麦克风权限，不主动弹框
  已授权      点按开始录音 → 再点停止；MediaRecorder 录制 webm/wav
  已拒绝      显示"如何开启权限"引导卡 + 提示"不影响您用文字或照片反馈"；
              语音按钮置灰，文字/照片通道照常可用（不卡死不降级主流程）
  录音完成    可试听 / 可重录 / 可删除；上传前本地暂存 audio blob

后端改动
  - app/api/portal.py · report()
     1) 接参：现有 request.files.getlist("photos") 之外，
        加 request.files.get("audio")。
     2) 校验放宽：把 len(text)<5 / len(normalized)<5 的硬判改为——
        若 photos 或 audio 非空则 text 可为空，否则维持 ≥5；
        len(text) > 2000 → len(text) > 1500，提示"请控制在 1500 字以内"。
     3) 音频落盘：存 data/evidence/audio/，文件名 uuid；
        校验 时长≤300s（5min）、大小≤15MB、类型白名单（webm/wav/m4a）。
     4) 关联诉求：音频路径写进 ResidentTicket.attachments
        （复用现有 JSON 机制，条目加 type=audio 标记）。
     5) 审计：AuditLog(actor=居民(尾号***), agent=portal,
        action="voice_upload")。
     6) 限流：复用 _rate_ok(f"voice:{phone}", ...)，与 report 共用滑动窗口。
     7) 去重命中分支同样要兼容音频（向旧单追加音频附件）。
     8) 照片存量上限：evidence.MAX_PHOTOS 5 → 10（含补传 room 计算）。

验收
  - 只文字 / 只照片 / 只语音 → 三种单独均可提交成功；
  - 文字+照片 / 文字+语音 / 照片+语音 / 三合一 → 四种组合均可提交；
  - 三通道全空 → 提示"至少选一种反馈方式"，不入库；
  - 拒绝麦克风 → 语音置灰、文字/照片照常；
  - 进度页可见该诉求使用了哪几种通道（依赖 P1-1 标签）；
  - 文字 >1500 字 → 400 拒绝；照片 11 张 → 提示超上限；
    语音 ≥5min → 拒绝或按 5min 截断提示。

【改动文件】report.html、portal.css、portal.py（report()）、
           evidence.py（MAX_PHOTOS）、config.py（MAX_CONTENT_LENGTH）。
