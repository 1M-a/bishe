三、模板：首页滚动条 + 关怀朗读衔接
------------------------------------------------------------
【文件 app/templates/portal/home.html｜body 顶部（CTA 卡之前）】

  要点：

    · 无预警时 {% if alerts %} 整体不渲染，页面不占位、不留空白；
    · 整体是一个 <a>，href 指向 alerts[0]（最新预警）的网页版详情，
      绝不放 notice_doc / notice?mode=print；
    · 记得贴 aria-live/role 不动基础可访问性。

【文件 app/templates/portal/home.html｜script 块（新加关怀循环朗读）】
  <script>
  document.addEventListener('DOMContentLoaded', function () {
    // 关怀模式 + 有预警 → 循环朗读预警文本。完全复用 xfCare.speak：
    // speak 内部已判 未开启/不支持/正在朗读 三条件，不满足就静默 return。
    // 非关怀模式自动不走朗读（设计如此，不是缺陷）。
    var items = Array.prototype.map.call(
      document.querySelectorAll('.p-alert-item'),
      function (el) { return el.textContent.trim(); }).filter(Boolean);
    if (!items.length || !window.xfCare) return;      // 无预警/未就绪静默跳过
    var text = '社区预警：' + items.join('。') + '。';
    function speakLoop() {
      window.xfCare.speak(text, { rate: 0.95 });
    }
    speakLoop();
    setInterval(speakLoop, 60000);                     // 每 60s 复查一次
  });
  </script>
  要点：
    · 循环用 setInterval 反复调 xfCare.speak，不自己造 SpeechSynthesis；
      speak 遇"正在朗读"会返回 false → 不打断详情页已有朗读、不重复播；
    · 首页循环朗读不中断详情朗读的口径与现有注释一致；
    · speak 自身静默失败 → 不报错、不影响页面。

【文件 app/templates/portal/notice.html / notice_doc.html】
  详情自动朗读逻辑（notice.html 现有 DOMContentLoaded + xfCare.speak）
  一律保留不动——用户明令"不要改"。
